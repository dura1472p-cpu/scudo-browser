Privacy Policy – Scudo Browser

Ultimo aggiornamento: 27 settembre 2026

Scudo Browser è un'estensione per Google Chrome progettata per proteggere l'accesso alla sessione di navigazione tramite una password configurata dall'utente.

Dati e funzionamento locale

Scudo Browser non invia allo sviluppatore password, cronologia di navigazione, contenuti dei siti web, posizione, dati finanziari o altre informazioni personali dell'utente.

La password scelta dall'utente non viene memorizzata in chiaro. L'estensione elabora localmente sul dispositivo i dati necessari alla verifica della password e memorizza localmente il relativo derivato crittografico, il salt e le impostazioni necessarie al funzionamento della protezione.

Accesso alle schede del browser

Scudo Browser utilizza l'autorizzazione relativa alle schede esclusivamente per rilevare la creazione e l'aggiornamento delle schede e applicare la schermata di protezione quando la sessione è bloccata. Le informazioni relative alle schede e alla navigazione non vengono trasmesse allo sviluppatore o a server esterni.

Condivisione e vendita dei dati

Scudo Browser non vende dati degli utenti e non trasferisce dati degli utenti a terze parti per pubblicità, profilazione, valutazione dell'affidabilità creditizia o altre finalità estranee allo scopo dell'estensione.

Supporto facoltativo

L'estensione può mostrare un collegamento facoltativo per supportare il progetto tramite PayPal. L'apertura di tale collegamento porta l'utente a un servizio esterno, soggetto alle condizioni e alla privacy policy del relativo fornitore. Scudo Browser non riceve né memorizza nell'estensione dati di pagamento.

Conservazione ed eliminazione

Le impostazioni dell'estensione e i dati necessari alla verifica della password sono conservati localmente tramite le API di archiviazione di Chrome. La rimozione dell'estensione elimina i dati conservati nell'area di archiviazione locale dell'estensione secondo il normale funzionamento di Chrome.

Chrome Web Store – Limited Use

L'uso delle informazioni ricevute dalle API di Google rispetta la Chrome Web Store User Data Policy, inclusi i requisiti di Limited Use. I dati accessibili all'estensione vengono utilizzati esclusivamente per fornire la funzione di protezione descritta e non per finalità non correlate.

Modifiche

Questa informativa potrà essere aggiornata qualora cambino le funzionalità o le modalità di trattamento dei dati di Scudo Browser. La versione pubblicata a questo indirizzo indicherà la data dell'ultimo aggiornamento.

Contatti

Per domande relative alla privacy di Scudo Browser, utilizzare i recapiti dello sviluppatore indicati nella relativa scheda del Chrome Web Store.
